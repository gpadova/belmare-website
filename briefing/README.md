# Briefing — arquivo histórico

O levantamento de **30/07/2026**, feito antes de existir uma linha de código. Está
aqui porque quinze arquivos de `src/` apontam para ele: quando um comentário explica
por que uma decisão foi tomada, é para cá que ele aponta.

⚠️ **Não governa nada.** Onde o briefing divergir do código, do `CONTEXT.md`, do
`PRODUCT.md` ou do `DESIGN.md`, **o que está construído vence** — e a divergência já
está registrada nesses arquivos, não aqui. Nada neste diretório deve ser atualizado
para "ficar em dia": um levantamento datado que alguém edita depois deixa de ser
levantamento e vira documento sem dono.
